# FlightQuiz — свой квиз для друзей

Готовый сайт на обычном HTML, CSS и JavaScript. Сервер, Node.js, платная подписка и API-ключи **не нужны**.

## Что умеет

- Добавлять собственные вопросы и выбирать готовые из списка (20 шаблонов).
- Использовать по 14 готовых ответов для каждого шаблона и добавлять до 40 вариантов на один вопрос.
- Задавать **вес** каждому ответу: сайт пересчитывает относительные проценты, сортирует варианты по весу и может случайно выбирать ответ с учётом этих весов.
- Назначать свой правильный ответ из списка **или** вписывать его вручную.
- Создавать ссылку на квиз, отправлять друзьям и показывать им результат после прохождения.
- Сохранять изменения автоматически в браузере, экспортировать и импортировать настройки в JSON.
- Работать на мобильных устройствах.

## Как опубликовать бесплатно на GitHub Pages

1. Зарегистрируйся на [github.com](https://github.com/).
2. Создай **Public** репозиторий, например `flightquiz` (**New repository**).
3. Нажми **Add file → Upload files**. Загрузи в корень репозитория **четыре файла**: `index.html`, `styles.css`, `data.js`, `app.js`. Можно также загрузить `README.md` и `.nojekyll`. Нажми **Commit changes**.
4. Зайди в **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**; Branch: **main**, Folder: **/(root)**. Сохрани (**Save**).
6. Когда публикация завершится, сайт откроется по адресу:

   `https://ТВОЙ-НИК.github.io/flightquiz/`

   `ТВОЙ-НИК` замени на свой логин GitHub. Если репозиторий называется иначе, используй его имя вместо `flightquiz`.

7. Открой сайт, измени вопросы и ответы, нажми **Создать ссылку** и отправь получившийся адрес друзьям.

**Важно:** загрузи именно отдельные файлы в корень репозитория, а не папку `flightquiz` целиком. Если загружаешь ZIP, предварительно распакуй его.

## Как запустить на компьютере

Открой `index.html` в современном браузере. Для локального сервера можно из папки с файлами запустить:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Как редактировать

**Проще всего прямо на сайте:** меняй текст вопроса, ответы и числа в колонке веса. Кнопка `✓` указывает правильный ответ. Кнопка **«Мой вариант ответа»** позволяет вписать свой текст. Кнопка **«Выбрать ответ по весам»** выбирает ответ случайно, учитывая заданные числа.

Чтобы изменить исходный список шаблонов **для всех новых посетителей**, отредактируй файл `data.js` в GitHub и сохрани изменения (Commit changes). Новые пользователи увидят обновлённые шаблоны. Пользователи, у которых есть локальные изменения, продолжат видеть свою сохранённую версию; для сброса есть кнопка **Сброс**.

Чтобы поделиться **конкретным составленным тестом** с друзьями, используй кнопку **Создать ссылку**. Настройки и ответы помещаются в адрес после `#quiz=` (упакованы с gzip, когда браузер поддерживает). Поэтому друзья увидят именно твой тест, даже без сервера.

Изменение теста после отправки ссылки **не меняет старую ссылку** — создай новую и отправь её заново.

## Ограничения бесплатной статической версии

- Настройки конструктора живут в браузере автора, а не синхронизируются между устройствами. Для переноса есть экспорт/импорт JSON.
- **Нет онлайн-таблицы результатов**: друзья видят собственный счёт и могут поделиться им. Чтобы автоматически получать все ответы в одном аккаунте, понадобится база данных (например, Supabase или Firebase).
- Ссылка содержит весь квиз и правильные ответы в закодированном виде — это **не защита от читерства**.
- Если создать очень большой тест с сотнями длинных ответов, ссылка получится длинной. Для обычных 10 вопросов и 14 коротких ответов на каждый размер обычно приемлем.
- Проценты — условная вероятность, вычисленная из заданных **весов**. Это не реальные статистические данные.

## Файлы

- `index.html` — разметка страницы.
- `styles.css` — дизайн и адаптивность.
- `data.js` — исходный банк вопросов, вариантов и весов.
- `app.js` — конструктор, выбор ответов, создание ссылок, игра и подсчёт результатов.
- `.nojekyll` — необязательная настройка GitHub Pages.
